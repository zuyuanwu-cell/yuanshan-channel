提示词怎么用

点「生成订阅」之后，页面给出一段提示词。复制后贴给 Cursor、ChatGPT、Claude、Grok 或其他 Agent，它会按你选的市场去读远山频道，总结平台规则、市场法规和热销榜。

同一次点击会把偏好交给 /oauth/api/subscribe，由服务器上的企业微信机器人发到群里。浏览器里没有 webhook 地址，页面也不发邮件。没配群机器人，或这页只是静态预览时，提示词照样生成，只是群里收不到。选择记在这台浏览器里，没有账号。

给程序

提示词里的地址来自同一套 /v1/。静态站点返回完整索引时，查询参数是筛选约定，由提示词要求 Agent 在读取时自己过滤。MCP 只读这些 JSON，不抓页面。

  • /v1.json 目录、筛选约定、以后的密钥形状
  • /v1/markets.json 市场 id、中文名、地区
  • /v1/updates.json 索引。静态托管忽略查询参数，由调用方按 markets、types、since 过滤
  • /v1/markets/{id}/feed.json 与 feed.xml 单市场，构建时已滤好
  • /v1/markets/{id}/compliance.json 该市场合规快照
  • /v1/markets/{id}/rankings.json 与 /v1/rankings/{board}.json

没有写入接口。不把无筛选的全库导出当作订阅。不生成法律意见，引用前打开来源链接。
